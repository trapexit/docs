# Documentation Repository

A collection of technical documentation including programming language specifications, hardware references, and ABI documentation.

## Contents

- [abi](./abi) - Application Binary Interface specifications for x86-64 and i386 systems
- [compilers](./compilers) - Compiler research papers covering register allocation and optimization
- [hardware](./hardware) - CPU and hardware documentation including ARM processor family
- [programming_languages](./programming_languages) - Programming language specifications (C, C++, APL) and references


## How to clone

```
git clone --depth 1 https://github.com/trapexit/docs.git
```
