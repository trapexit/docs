# 6502 Documentation

Curated primary-source documentation for MOS Technology's original MCS6500 family and
Western Design Center's current 65xx implementations. The collection deliberately excludes
secondary tutorials, unofficial opcode references, and redistributions of unknown origin.

## Original MOS Technology publications

These are scans of documents published by MOS Technology. They are supplied here from
[Bitsavers](https://bitsavers.org/), a preservation archive; it is the host, not the original
publisher. Publication date and document number come from the documents themselves.
