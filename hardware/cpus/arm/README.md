# ARM

ARM architecture documentation and reference materials. Covers ARM processor families from ARM1 through ARM11.

## Subdirectories

- [ARM1](./ARM1) - First ARM processor (1985), 26-bit architecture, developed by Acorn Computers
- [ARM2](./ARM2) - Second-generation ARM processor with improved performance and multiply instructions
- [ARM3](./ARM3) - Third-generation ARM processor with integrated cache support
- [ARM6](./ARM6) - ARM6 family including ARM60, ARM610, and ARM710 processors
- [ARM7](./ARM7) - Popular embedded processor family with ARM7TDMI variants and Thumb support
- [ARM9](./ARM9) - ARMv5 architecture processors with improved performance
- [ARM11](./ARM11) - ARMv6 architecture processors with SIMD and multimedia extensions
- [ARM250](./ARM250) - Integrated ARM2 with FPU and video controller
- [misc](./misc) - General ARM programming guides, architecture references, and assembly language tutorials
