# C Programming Language

C language specifications, standards, and reference materials.

## Files

- [C - ISO IEC 9899:1990](./C%20-%20ISO%20IEC%209899:1990.pdf) - The original C standard defining the C programming language syntax, semantics, and library
- [C - ISO IEC 9899:1999 - N1256](./C%20-%20ISO%20IEC%209899:1999%20-%20N1256.pdf) - C99 standard with new features including inline functions, variable-length arrays, and improved numeric precision
- [C - ISO IEC 9899:2011 - N1570](./C%20-%20ISO%20IEC%209899:2011%20-%20N1570.pdf) - C11 standard introducing multithreading support, anonymous structures, and Unicode support
- [C - ISO IEC 9899:2017 - N2176](./C%20-%20ISO%20IEC%209899:2017%20-%20N2176.pdf) - C17 standard focusing on bug fixes and clarifications to C11
- [C - ISO IEC 9899:2023 - N3467](./C%20-%20ISO%20IEC%209899:2023%20-%20N3467.pdf) - C23 standard with new features including static assert, attributes, and improved Unicode support
- [C - ISO IEC 9899:2024 - N3220](./C%20-%20ISO%20IEC%209899:2024%20-%20N3220.pdf) - Latest C standard (C24) with further language refinements
- [Computer Systems A Programmer's Perspective - Randel E. Bryant, David R. O'Hallaron (2016)](./Computer%20Systems%20A%20Programmer's%20Perspective%20-%20Randel%20E.%20Bryant,%20David%20R.%20O'Hallaron%20(2016).pdf) - Comprehensive textbook on computer systems, data representations, machine code, processor architecture, and performance optimization
- [Essential C - Nick Parlante (2003)](./Essential%20C%20-%20Nick%20Parlante%20(2003).pdf) - Stanford CS Education document covering C basics: variables, types, operators, control structures, functions, structs, pointers, arrays, preprocessor, and standard library
- [Modern C - Jens Gustedt (2024)](./Modern%20C%20-%20Jens%20Gustedt%20(2024).pdf) - Third edition covering C23 standard from INRIA France, focusing on modern C programming techniques
- [The C Programming Language - Brian W. Kernighan, Dennis M. Ritchie (1978)](./The%20C%20Programming%20Language%20-%20Brian%20W.%20Kernighan,%20Dennis%20M.%20Ritchie%20(1978).pdf) - The definitive original book on C by its creators, describing the pre-ANSI C language
- [The C Programming Language, Second Edition - Brian W. Kernighan, Dennis M. Ritchie (1988)](./The%20C%20Programming%20Language,%20Second%20Edition%20-%20Brian%20W.%20Kernighan,%20Dennis%20M.%20Ritchie%20(1988).pdf) - Updated edition covering ANSI C standard, the classic C reference
