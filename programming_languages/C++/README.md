# C++ Programming Language

C++ language specifications, standards, and reference materials.

## Files

- [C++ ISO IEC 14882:1998](./C++%20ISO%20IEC%2014882:1998.pdf) - First ISO C++ standard defining the language syntax, standard library, and object model
- [C++ ISO IEC 14882:2003](./C++%20ISO%20IEC%2014882:2003.pdf) - C++03 standard, minor technical correction release
- [C++ ISO IEC 14882:2011](./C++%20ISO%20IEC%2014882:2011.pdf) - C++11 major standard introducing lambdas, smart pointers, move semantics, multithreading support, and range-based for loops
- [C++ ISO IEC 14882:2014](./C++%20ISO%20IEC%2014882:2014.pdf) - C++14 standard with generic lambdas, variable templates, digit separators, and relaxed constexpr rules
- [C++ ISO IEC 14882:2017](./C++%20ISO%20IEC%2014882:2017.pdf) - C++17 major standard featuring structured bindings, if constexpr, filesystem library, optional/variant/any types, and parallel algorithms
- [C++11 Working Draft - N3242](./C++11%20Working%20Draft%20-%20N3242.pdf) - Early C++11 working draft document
- [C++11 Working Draft - N3337](./C++11%20Working%20Draft%20-%20N3337.pdf) - C++11 working draft close to final standard
- [C++14 Working Draft - N3797](./C++14%20Working%20Draft%20-%20N3797.pdf) - C++14 working draft document
- [C++14 Working Draft - N4140](./C++14%20Working%20Draft%20-%20N4140.pdf) - C++14 working draft near final specification
- [C++17 Working Draft - N4659](./C++17%20Working%20Draft%20-%20N4659.pdf) - C++17 working draft
- [C++17 Working Draft - N4660](./C++17%20Working%20Draft%20-%20N4660.pdf) - C++17 working draft final version
- [C++20 Working Draft - N4849](./C++20%20Working%20Draft%20-%20N4849.pdf) - C++20 working draft introducing concepts, ranges, coroutines, modules, and designated initializers
- [C++20 Working Draft - N4860](./C++20%20Working%20Draft%20-%20N4860.pdf) - C++20 working draft near final state
- [C++23 Working Draft - N4950](./C++23%20Working%20Draft%20-%20N4950.pdf) - C++23 working draft with further language improvements and library enhancements
